Agents are especially vulnerable to state confusion because they can process hundreds of opportunities at once. If an agent collapses opportunity, accepted, queued, and settled into one number, it can make bad decisions immediately: send duplicate claims, assume a payout exists, or try to spend value that is still only a promise. A safer agent keeps each state separate and attaches evidence to every transition. An open bounty is an opportunity. A maintainer acceptance is a receivable. A pending transfer is queued value. A wallet receipt is settled value. Only the final state should be treated as money already received.
