# $50k Blockchain Sprint — 2026-09-04

Target: $50,000 gross opportunity value in one day. This is a stretch target, not a guaranteed result.

## Accounting rules

Count as **cash / realized** only when a payout or settled on-chain receipt exists.
Count as **executable** only when a stateful latest-state fork succeeds and modeled costs remain positive.
Count as **candidate** when external data/API suggests an opportunity but execution has not passed the fork gate.
Never count duplicate polling, stale API data, reverted simulations, unfunded bounties, or hypothetical spreads.

DISCOVER

## Kill conditions
- API says liquidatable but fork reverts: reject.
- Bounty is unfunded / regional-ineligible / expired: reject.
- Requires spending capital with negative or unclear expected value: reject.
- Requires fabricated engagement, fake identities, or self-dealing: reject.

## Stretch math
To reach $50k in one day from $0 requires one or more outsized events (large competition/grant win, major solver capture, or multiple large bounties). Small micro-bounties are only seed capital and cannot mathematically close the target alone.
