# Script — 52–58 seconds

**Hook:** What if an old PowerPC could matter more than a brand-new server?

RustChain uses Proof of Antiquity. The baseline idea is simple: **one physical CPU, one vote**.

But before a machine participates, RustChain uses hardware attestation and fingerprint checks to decide whether it looks like real hardware instead of an easily cloned virtual machine.

Then age affects the reward weight: vintage and exotic hardware can receive an antiquity multiplier, while virtualized environments are heavily discounted or rejected by the attestation logic.

So the goal is not “who owns the biggest GPU farm?” It is closer to: **can you prove this is a real, distinct piece of silicon — and how historically rare is it?**

That is RustChain’s Proof of Antiquity.
