Bounty: Scottcjn/rustchain-bounties #315
Author: @markabramov1993

## Creative direction

Human-first awareness. The recurring contrast is simple: **old hardware still has value**. Avoid price promises, guaranteed earnings, or technical overload. Visuals should feel tactile and real: beige PCs, CRT glow, scratched laptops, old keyboards, terminal text, hands powering machines on.

## 3 vertical video script templates (8–15 seconds)

### Short A — “Don’t recycle it yet” (12s)

**0–2s — Hook / visual:** Hand carries an old laptop toward an e-waste box.
**On-screen:** “WAIT. Don’t recycle it yet.”

**2–7s — Turn:** Laptop lands on desk, powers on, terminal opens.
**VO:** “RustChain gives old hardware one more reason to stay useful.”
**On-screen:** “Old hardware → real network participation”

**7–10s — Proof cue:** Fast terminal close-up / hardware detection output.
**VO:** “Start with a safe dry run.”

**10–12s — CTA:**
**On-screen + VO:** “Try it: rustchain.org”

**Production note:** Real-device footage preferred. No token-price graphics.

### Short B — “New vs old” (10s)

**0–2s:** New laptop on left, vintage machine on right.
**On-screen:** “Which one matters more?”

**2–6s:** New machine fades; old machine boots.
**VO:** “RustChain flips the usual upgrade story: age can be part of the value.”

**6–8s:** Terminal / hardware-check shot.
**On-screen:** “Proof of Antiquity”

**8–10s:**
**VO + CTA:** “Dust yours off. rustchain.org”

**Production note:** Say “can be part of the value,” not “old always earns more.”

### Short C — “Garage challenge” (15s)

**0–3s:** Camera sweeps across boxes / garage shelf.
**VO:** “Find the oldest computer you still own.”
**On-screen:** “GARAGE CHALLENGE”

**3–7s:** Machine on desk, power button press.
**VO:** “If it boots, give it one more job.”

**7–11s:** Terminal shows RustChain dry-run / detected hardware.
**VO:** “Run RustChain, inspect the hardware checks…”

**11–15s:** Wide shot of machine running.
**VO:** “…and show us what survived.”
**On-screen:** “Start → rustchain.org”

**Production note:** Keep machine identity/model visible for authenticity.

## Publishing / QA notes

- Keep `rustchain.org` visible in every asset.
- Do not promise profit, ROI, token price appreciation, or guaranteed rewards.
- Prefer footage/photos of real hardware over generic crypto animation.
- Keep captions readable without sound; burn in subtitles for video.
- For Shorts/TikTok, first meaningful text should appear in the first second.
- If a machine is shown running the miner, use genuine output or a clearly labeled mockup — never fabricate a successful run.
